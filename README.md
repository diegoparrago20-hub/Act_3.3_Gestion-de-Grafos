# Act_3.3_Gestion-de-Grafos
Este proyecto consiste en el desarrollo de una aplicación de escritorio en Java que permite representar y gestionar grafos mediante una interfaz gráfica.

# Objetivo
Implementar una aplicación que permita trabajar con grafos, administrar sus elementos y aplicar algoritmos de recorrido para analizar las conexiones entre los vértices.

# Tecnologías utilizadas
Java
Java Swing
Apache NetBeans
Git y GitHub

# Características
Creación y administración de grafos.

Registro de vértices con identificadores únicos.

Validación de identificadores duplicados.

Conexión entre vértices mediante aristas con peso.

Búsqueda de vértices.

Eliminación de vértices y sus conexiones.

Recorrido mediante BFS (Búsqueda en Anchura).

Recorrido mediante DFS (Búsqueda en Profundidad).

Visualización de la matriz de adyacencia.

Consulta de conectividad del grafo.

Opción para eliminar todos los elementos del grafo.

Validación de datos y campos obligatorios.

#Estructura del proyecto
Clase Grafo: administra los vértices y las conexiones del grafo.

Clase Vertice: representa cada nodo del grafo mediante un identificador.

Clase Arista: representa las conexiones entre vértices y almacena su peso.

Algoritmos BFS y DFS: permiten recorrer los vértices del grafo mediante búsqueda en anchura y profundidad.

Interfaz gráfica: permite interactuar con las operaciones del grafo mediante formularios, botones y paneles.

# Interfaz gráfica
La interfaz se realiza en NetBeans mediante componentes de Java Swing, organizando los campos, botones y áreas de visualización para facilitar la administración de vértices, conexiones y recorridos del grafo.
